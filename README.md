## 📖 これは何？

「運勢・天命乃杜」は、大吉から大凶まで**忖度なしの 12 段階確率**で今日の運勢を占える、Web ブラウザ完結型のおみくじサイトです。

名前なしでもその場でおみくじを引けます。名前なしで引いた結果は、履歴・運勢値・統計などへ保存されません。参拝者名を設定した場合やログイン中でも、**環境・表示設定の「おみくじを履歴へ保存」**を OFF にすれば結果を保存しない選択ができます。

## ✨ 主な機能

### 占い

- **今日の運勢おみくじ** — 大吉〜大凶の 12 段階、忖度なしの確率設計
- **最強運勢ランキング** — 12 星座 × 4 血液型、全 48 通りの組み合わせをランキング表示
- **AI 夢占い / AI 悩み相談** — 夢占いはログインが必要で、夢の本文と AI の解釈を夢の記録として保存。悩み相談はログイン不要で、その場限りの表示（相談内容・回答はデータベースに保存しません）

### 記録・コレクション

- **おみくじの轍** — 参拝者名またはログインで利用可能。保存設定を OFF にすると記録しない
- **デジタル御守** — 8 種類の願いから選んで御守画像を作成し、端末へ保存
- **お気に入り機能**

### コミュニティ・データ

- **全国・土地の運気** — 47 都道府県の運勢ランキングを一覧・地図で表示
- **本日の傾向(統計)** — 全体の参拝数や大吉獲得数などを可視化
- **公式 Discord 参拝所**
- **サービス状況ページ** — サービスの稼働状況と監視情報を公開

### 読み物・その他

- **社務所だより・神籤草子** — お知らせ・コラム記事を掲載。記事本文の AI 要約にも対応
- **TENMEI Labs(実験室)** — 隠し要素・実験的 UI を先行体験できるセクション
- **読みものの表示設定** — 環境・表示設定から、通常の記事だけでなく「当サイトについて」「プライバシーポリシー」「使い方」へ同じ読書設定を適用可能。SPA で画面を切り替えても設定を再適用します
- **翻訳** — 英語・韓国語・中国語（簡体字／繁体字）・フランス語・ドイツ語・スペイン語・ポルトガル語・ベトナム語・インドネシア語・タイ語に対応。ChatGPTが作成した文脈対応の静的翻訳辞書のみを使用し、未収録の項目は日本語のまま表示します。旧機械翻訳辞書や翻訳APIによる補完は行わず、閲覧者の端末に翻訳モデルをダウンロードさせません。
- **ログイン** — メールアドレス(認証コード／マジックリンクログイン)または Google アカウントに対応

## 🧩 開発者・AI エージェント向け公開リソース

- **公開 API / OpenAPI** — メンテナンス状態と公開カウンターを取得できる、認証不要・読み取り専用の API を公開しています。
- **Public MCP サーバー** — サイト情報・公開リソース一覧・サービス状況を取得する読み取り専用ツールを提供します。訪問者アカウント、個人データ、書き込み操作、AI 生成機能は公開していません。
- **仕様・接続先**: [API ガイド](./docs/agents/api.md) / [OpenAPI](./openapi.json) / [MCP エンドポイント](https://tenmei-mori-mcp.nden14800.workers.dev/mcp)
- **エージェント認証** — 外部エージェント向け OAuth 2.0 / OpenID Connect 認証は提供していません。サイト上の人間向けログインを外部エージェント認証として使用することはできません。

## 🛠 技術スタック

- **ホスティング**: Cloudflare Pages
- **バックエンド**: Cloudflare Workers
- **データベース**: Turso(LibSQL / SQLite 互換のエッジデータベース)
- **AI 機能基盤**: Cloudflare Workers AI
- **AI 案内**: 独自実装（Cloudflare Workers AI の GLM-4.7-Flash）。Cookie 設定でサポートチャットを許可した場合のみ読み込み、会話履歴はサイトのデータベース・アカウント・ブラウザー内ストレージに保存しません。
- **翻訳**: 同一サイト配信の静的JSON辞書。ChatGPT作成の翻訳だけを表示し、未収録の項目は日本語のまま表示します。ブラウザー側の翻訳エンジン・モデル取得は不要です。
- **アクセス解析**: Google Analytics / Microsoft Clarity（Cookie 設定で「利用状況の解析」を許可した場合のみ）
- **メール送信**: Maileroo

## 🤖 独自 AI 案内

サイトの使い方・機能案内には、独自の AI 案内を使用しています。

- **実装**: `assets/js/tenmei-ai-agent.js` と `assets/css/tenmei-ai-agent.css`
- **バックエンド**: `workers/tenmei-mori-backend.js` の `/api/ai-guide`
- **モデル**: Cloudflare Workers AI `@cf/zai-org/glm-4.7-flash`
- **指示文**: バックエンドの `/api/ai-guide` にある `systemPrompt`。サイト機能、保存仕様、回答手順、プライバシー、安全性、分からない仕様を捏造しないルールを定義しています。
- **入力・文脈**: 今回の質問、直近の会話（最大10件）、送信時のページタイトル、画面内で見えている見出し（最大8件）、操作ラベル（最大12件）を回答生成に使用します。操作ラベルには画面上の位置区分も含みます。画面情報に入力欄の値は含めません。
- **会話履歴**: AI 案内の会話履歴は画面上のセッション内でのみ保持します。会話本文はデータベース・アカウント・ブラウザー内ストレージへ保存しません。
- **利用条件**: Cookie 設定でサポートチャットを許可した場合のみ読み込みます。
- **制限**: AI 案内はサイトを直接操作したり、利用者のアカウントや履歴を閲覧したり、サイトの最新状態をリアルタイム検索したりできません。確認していない画面配置・仕様・障害状況を断言しないよう指示しています。

AI の指示文やサイト仕様を更新した場合は、`tests/ai-help-desk-ui-regression.cjs` の回帰チェックも更新してください。

## 🚀 使い方

1. [https://tenmei-mori.pages.dev/](https://tenmei-mori.pages.dev/) にアクセス
2. トップページから「おみくじを引く」を選択
3. 名前なしでも引けます。名前を付ける場合は参拝者名を設定
4. 保存したくない場合は、環境・表示設定の「おみくじを履歴へ保存」を OFF にする
5. 結果を確認。参拝証を発行すると、アカウントに紐づく参拝記録・お気に入り・AI 夢占い・TENMEI Labs などを利用できます。AI 夢占いの入力内容と解釈は夢の記録として保存されます

## 📦 本番デプロイ

本番サイトは Cloudflare Pages の GitHub 連携で `main` ブランチを監視しており、`main` への push を契機に本番デプロイされます。Cloudflare Pages の Git 連携では、production branch 以外はプレビュー環境として扱われます（実際のプレビュー作成はブランチ制御設定に従います）。詳しくは [Cloudflare Pages の Git integration](https://developers.cloudflare.com/pages/configuration/git-integration/) を参照してください。

GitHub Actions の `Deploy Cloudflare Pages` ワークフローは、現在の Cloudflare Pages Git 連携による自動デプロイとは別系統です。通常の本番更新では、変更を `main` に取り込み、Cloudflare Pages のデプロイ完了を確認してください。

`work` などの作業ブランチへのコミットだけでは本番デプロイは実行されません。変更を `main` に取り込んでから本番サイトを確認してください。

## ⚙️ 設定について

設定は**環境・表示設定**を正本として一元管理しています。従来の「使い方」ページにあった重複した設定項目は廃止し、読書設定を本体へ統合しています。

「読書設定」ではフォントサイズ、行間、本文フォント、コンテンツ幅などの読みやすさを調整でき、さらに「当サイトについて」「プライバシーポリシー」「使い方」への適用も切り替えられます。

Cookie 設定では、AI 案内、利用状況の解析などの外部サービスを個別に許可・拒否できます。解析を OFF にするとアクセス解析用の同意状態も拒否へ戻ります。
