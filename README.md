## 📖 これは何？

「運勢・天命乃杜」は、大吉から大凶まで**忖度なしの12段階確率**で今日の運勢を占える、Webブラウザ完結型のおみくじサイトです。

名前なしでもその場でおみくじを引けます。名前なしで引いた結果は、履歴・運勢値・統計などへ保存されません。参拝者名を設定した場合やログイン中でも、**環境・表示設定の「おみくじを履歴へ保存」**をOFFにすれば結果を保存しない選択ができます。

## ✨ 主な機能

### 占い
- **今日の運勢おみくじ** — 大吉〜大凶の12段階、忖度なしの確率設計
- **12星座 × 血液型占い** — 48通りの組み合わせパターン
- **AI夢占い / AI悩み相談** — AIを活用した占い・相談機能(悩み相談はログイン不要、その場限りの表示)

### 記録・コレクション
- **おみくじの轍** — 参拝者名またはログインで利用可能。保存設定をOFFにすると記録しない
- **デジタル御守** — 願いに合わせて作成・保存できるオリジナル御守
- **お気に入り機能**

### コミュニティ・データ
- **全国運気ランキング** — 都道府県別の運勢を毎日更新
- **本日の傾向(統計)** — 全体の参拝数や大吉獲得数などを可視化
- **公式Discord参拝所**

### 読み物・その他
- **コラム記事・お知らせ** — 運勢や占いにまつわる読み物コンテンツ(AIによる記事要約機能つき)
- **TENMEI Labs(実験室)** — 隠し要素・実験的UIを先行体験できるセクション
- **読みものの表示設定** — 環境・表示設定から、通常の記事だけでなく「当サイトについて」「プライバシーポリシー」「使い方」へ同じ読書設定を適用可能
- **翻訳** — Bergamot系のローカル翻訳エンジンを使い、翻訳本文を外部翻訳APIへ送信せずにブラウザ内で翻訳
- **ログイン** — メールアドレス(認証コード／マジックリンクログイン)またはGoogleアカウントに対応

## 🛠 技術スタック

- **ホスティング**: Cloudflare Pages
- **バックエンド**: Cloudflare Workers
- **データベース**: Turso(LibSQL / SQLite互換のエッジデータベース)
- **AI機能基盤**: Cloudflare Workers AI
- **AI案内**: Chatling（Cookie設定で明示的に許可した場合のみ読み込み。OFFにすると読み込み済みウィジェットも停止・除去）
- **翻訳**: `@browsermt/bergamot-translator` 0.4.9 + Firefox Translations系モデル。モデルをブラウザ側へ取得してローカル処理する方式
- **アクセス解析**: Google Analytics / Microsoft Clarity（Cookie設定で「利用状況の解析」を許可した場合のみ）
- **メール送信**: Maileroo

## 🚀 使い方

1. [https://tenmei-mori.pages.dev/](https://tenmei-mori.pages.dev/) にアクセス
2. トップページから「おみくじを引く」を選択
3. 名前なしでも引けます。名前を付ける場合は参拝者名を設定
4. 保存したくない場合は、環境・表示設定の「おみくじを履歴へ保存」をOFFにする
5. 結果を確認。参拝証を発行すると、対応する記録・お気に入り・AI夢占い・TENMEI Labsなどの機能をアカウント単位で利用できます

## ⚙️ 設定について

設定は**環境・表示設定**を正本として一元管理しています。従来の「使い方」ページにあった重複した設定項目は廃止し、読書設定を本体へ統合しています。

「読書設定」ではフォントサイズ、行間、本文フォント、コンテンツ幅などの読みやすさを調整でき、さらに「当サイトについて」「プライバシーポリシー」「使い方」への適用も切り替えられます。

Cookie設定では、AI案内、利用状況の解析などの外部サービスを個別に許可・拒否できます。解析をOFFにするとアクセス解析用の同意状態も拒否へ戻ります。
