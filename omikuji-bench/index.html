評価方法

同じ条件で実際に操作し、証拠のある項目だけを採点します。

SCORING FRAMEWORK
100点満点

6つの評価軸を合算。未確認項目は0点ではなく「N/A」とし、確認できた範囲・根拠・信頼度を明示します。複数AI評価者の平均とばらつきも公開します。

01
体験・操作性 — 25点

初回導線、操作ステップ、スマホ操作、結果画面、アクセシビリティ。

02
結果の品質 — 20点

文章の具体性、一貫性、読みやすさ、項目の充実度。

03
機能・継続性 — 15点

履歴、共有、保存、日替わり要素、追加コンテンツ。

04
透明性・安心 — 20点

抽選/生成方式、確率・集計の根拠、プライバシー、広告・課金表示。

05
独自性・表現 — 10点

世界観、ビジュアル、音・演出、他サービスとの違い。

06
安定性・技術 — 10点

主要導線の完走、エラー回復、レスポンシブ、LCP/INP/CLS。

公平性と検証の原則

評価の過程と限界も公開します。

評価の原則

①公式情報と実測を区別する　②未確認を0点にしない　③少数サンプルから抽選の不正や偏りを断定しない　④第三者サイトに過剰アクセスしない　⑤評価基準と変更履歴を公開する　⑥占いの的中率や信仰上の価値は採点しない。

外部基準：WCAG 2.2 ↗ ・ Core Web Vitals ↗

AIの印象だけで点数を確定せず、最低3評価者の独立レビューとブラウザ操作の証拠を組み合わせます。評価者の不一致・信頼度・未確認項目を併記します。
