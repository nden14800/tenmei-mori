05 / METHODOLOGY

Index 3.0 · 評価方法

6カテゴリ・24評価項目。公式公開情報に基づくデスクレビューと、実測していない指標の区別を明示。

METHODOLOGY 3.0
24項目の採点方式：各サイトの公開ページ、FAQ、プライバシーポリシー、更新履歴などから項目ごとに0〜100点でデスクレビュー。最初の16項目は個別評価。追加8項目は関連する評価項目と公式説明を照合した補助評価で、実機計測や独立監査ではない。明示された機能・仕様は加点し、確認できない機能は加点しない。アクセシビリティは公開情報上の配慮、技術配慮は公開された実装説明・データ取扱いのみを評価し、実機操作・Lighthouse・WCAG監査・速度・稼働率・乱数品質の実測値とは区別する。確信度は根拠の確認量を示し、採点精度の保証ではない。

採点式：24項目の加重平均で総合Indexを算出。各カテゴリは該当項目の加重平均です。追加8項目は関連項目を基にした補助採点であり、独立した実機試験結果ではありません。
採点基準：90〜100＝明確で充実した公開仕様・体験、75〜89＝良好、60〜74＝基本要件を満たす、40〜59＝情報・機能が限定的、0〜39＝確認できる根拠が乏しい。未確認は機能が存在しないと断定せず、公開情報で裏付けられた範囲のみを採点します。
未実測項目：Core Web Vitals、Lighthouse、実端末の読み込み速度、稼働率、スクリーンリーダー適合、抽選の統計的公平性は測定していません。技術配慮点は公開された仕様・説明の確認範囲に限ります。
確信度：高＝公式ページに複数の具体的説明がある、中＝主要機能は確認できるが一部詳細が不足、低＝公開情報が限られるか対象適合性に留保。確信度は点数の正確さを保証しません。
対象範囲：日本語で利用できる一般利用者向けWebおみくじ・おみくじメーカーを対象。スマートフォン専用アプリ、企業向け受託システム、神社の実物授与品は別カテゴリとし、同一ランキングには混ぜません。
