# OmikujiBench

オンラインおみくじ・関連サービスを、体験品質と公開情報に基づいて比較する独立ベンチマーク。

## 公開URL
https://tenmei-mori.pages.dev/omikuji-bench/

## 実装方針
- tenmei-moriと同じGoogle Fonts（Zen Kaku Gothic New / Zen Old Mincho / Shippori Mincho）とBootstrap Iconsを採用。
- 共通の和モダンな書体・余白・フォーカス・ダークモード設計を踏襲。OmikujiBench独自の抽象的な多色シンボルを使用し、漢字一文字のロゴは使用しない。
- 単一HTML/CSS/JavaScript、外部ビルド不要。Cloudflare Pagesの既存ルート配信を利用し、omikuji-bench/に独立配置。
- 検索、カテゴリ絞り込み、並べ替え、カード/表切替、お気に入り、最大3件比較、詳細評価、SVGランキンググラフ、カテゴリ平均、比較表、CSV出力、ライト/ダーク/システム連動に対応。
- モバイル、デスクトップ、キーボードフォーカス、reduced motionを考慮。

## 一次評価の公開状況
- 18サイトを登録し、2026-10-25の公式ページ公開情報に基づく単独AIの暫定デスクレビューを掲載。
- 点数は複数AIの平均ではなく、実機ブラウザの測定値でもない。各サイトの詳細で根拠・確信度・未検証事項を確認できる。
- 天命の杜も他サイトと同じ採点軸・配点で評価し、所有者による加点はしない。
- 安定性点を含む全項目は暫定の公開情報評価。速度・実操作・アクセシビリティ適合は未測定。
- 正式評価では3つ以上のAI評価者、ブラウザ操作、LCP/INP/CLS、アクセシビリティ検証を追加する。

## 公平性ルール
- 公式情報・実測・AI主観評価を分離する。
- 未確認情報は確認済みとして扱わない。
- 少数サンプルから抽選不正や確率の偏りを断定しない。
- robots.txt、利用規約、レート制限を尊重する。
- 占いの的中率・信仰上の価値は採点しない。
- アクセシビリティはWCAG 2.2、パフォーマンスはCore Web Vitalsを参考にする。
