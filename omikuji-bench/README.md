# OmikujiBench v4.0

オンラインおみくじ29サイトを、公開ページで確認できた22のチェックポイントで比較する独立ベンチマークです。

## 概要

- 判定は各項目 1（明記）/ 0（確認し明確に無い）/ ?（判断不能・除外）の3値です。
- 点数は確認できた項目だけで計算します。? は分子にも分母にも入りません。
- 項目の重みは素数（2〜79）で、同じ組み合わせ以外で端数の少ない値に揃うのを避けています。
- v3.5 までの16項目・旧採点は廃止しました。旧スコアは引き継いでいません。

## 判定の状態（2026-10-30）

- 算出対象: 27サイト
- 算出対象外: 2サイト
  - omikuji-jp: 本文を取得できず（meta情報のみ）、全項目 ? のため
  - toolsnavi（ツールナビ おみくじ）: 取得エラーのため判定不能

## 集計

- カテゴリ別スコア \(S_c = \frac{\sum_{j \in V_c} w_j x_j}{\sum_{j \in V_c} w_j} \times 100\)
- Index \(= \frac{\sum_{c} W_c S_c}{\sum_{c} W_c}\)（判定済み項目を持つカテゴリのみ）
- 算出条件: 判定済み項目 60% 以上、かつ 5 カテゴリ中 4 つ以上で判定済み
- 信頼度: 判定済み 75% 以上を「高」、55% 以上を「中」、それ未満を「低」

## カテゴリと項目

|---|---|---|

各項目の定義と重みは `evaluation-rubric.json` と `data.js` の `OB_CHECKS` にあります。

## ファイル

- `index.html`: 表示ページ（ランキング・分析・一覧・マトリクス・方法）。tenmei-mori と同じ選択欄・入力欄の意匠を使用
- `data.js`: 単一の情報源（カテゴリ・項目・29サイトの判定コード、根拠、出典）
- `evaluation-rubric.json`: v4.0 の評価基準
- `vendor/echarts.min.js`: ECharts 6.1.0（Apache-2.0、`vendor/ECHARTS-LICENSE.txt`）
- `favicon.svg`, `favicon.ico`, `favicon-96x96.png`, `apple-touch-icon.png`: アイコン
- `INITIAL-REVIEW.md`: 旧 v1.2 の記録（参考）

## 注意

- 点数は単一レビュアーによる公開情報の机上確認です。実機の動作測定や多人数評価の平均ではありません。
- 視覚品質、表示速度（LCP・INP・CLS）、抽選確率の数値は採点していません。
- 確率は推測しません。F4 は確率や方式が公開されているかのみを判定します。
- 自サイト（tenmei-mori）も同じ基準で判定し、ボーナスや減点はありません。
