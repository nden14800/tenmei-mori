# OmikujiBench

オンラインおみくじサイトを、体験・結果品質・機能・透明性・独自性・安定性から評価する独立ベンチマーク。

## 公開URL
https://tenmei-mori.pages.dev/omikuji-bench/

## 配置・デプロイ
このサイトは `nden14800/tenmei-mori` の `omikuji-bench/` に独立配置する。既存のCloudflare Pagesプロジェクト `tenmei-mori` はリポジトリルートを公開するため、専用Pagesプロジェクトや専用デプロイworkflowは作らない。既存のmainデプロイが成功すればこのパスに反映される。既存のルート・status実装は変更しない。

## 現在の状態
- 静的HTML/CSS/JavaScript。ビルド・外部ライブラリ不要
- サイト検索、カテゴリ絞り込み、概要ダイアログ、ライト/ダーク両対応
- 公式ページで確認できた候補を登録
- **スコア・順位は未公開**。実機テストと複数AI評価を実施してから公開
- tenmei-moriも他サイトと同一条件で評価する

## 評価配点
| 項目 | 配点 |
|---|---:|
| 体験・操作性 | 25 |
| 結果の品質 | 20 |
| 機能・継続性 | 15 |
| 透明性・安心 | 20 |
| 独自性・表現 | 10 |
| 安定性・技術 | 10 |
| 合計 | 100 |

## 公平性ルール
- 公開情報、ブラウザ実測、AIの主観評価を分けて保存
- 未確認項目は0点ではなくN/A
- 可能な範囲でサイト名を伏せて最低3つのAI評価者が独立採点
- 平均・ばらつき・根拠・信頼度を記録
- robots.txt・利用規約・レート制限を尊重し、第三者サイトへ大量アクセスしない
- 抽選確率は公式説明と実測を区別し、少数サンプルから不正や偏りを断定しない
- 占いの的中率や信仰上の価値は採点しない
- アクセシビリティはWCAG 2.2、パフォーマンスはCore Web Vitalsを参考にする

## ファイル
- index.html: 公開フロントエンド
- evaluation-rubric.json: 機械可読な配点・採点ルール
- INITIAL-REVIEW.md: 初回デスクレビュー（正式採点ではない）

## 次の工程
1. 各候補をモバイル/デスクトップで主要導線を確認
2. 結果画面、エラー回復、キーボード操作、フォーカスを記録
3. LCP/INP/CLSは測定条件・回数を添えて記録
4. 3つ以上のAI評価者が根拠付きJSONを提出
5. 不一致と未確認項目をレビューしてからスコアを公開
